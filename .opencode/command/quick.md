Мелкая задача: $ARGUMENTS

Правила:

- Если правка меняет API или поведение пакета — остановись и предложи использовать /task (спеки должны обновляться).
- Читай спеку только для понимания, НЕ редактируй её.
- Тесты: testify.Assert*, предпочтительно table-driven.
- В конце обязательно все 4 команды, при падении — чини и гоняй заново:

```bash
go fmt ./...
go vet ./...
go test -race ./...
go fix ./...
```
