Мелкая задача: $ARGUMENTS

Правила:

- Если правка меняет API или поведение пакета — остановись и предложи использовать /task (спеки должны обновляться).
- Ветка обязательна (ADR-021): работай на `chore/<slug>` (`git switch -c chore/<slug>`, если ещё не на ней).
  Никаких feature-flag/env/kill-switch в коде — переключателем служит сама ветка.
- Читай спеку только для понимания, НЕ редактируй её.
- Тесты: testify.Assert*, предпочтительно table-driven.
- В конце обязательно все 4 команды, при падении — чини и гоняй заново:

```bash
go fmt ./...
go vet ./...
go test -race ./...
go fix ./...
```

- Закрытие: закоммить в chore-ветку и слей squash'ом в `main` по skill `workflow` → Закрытие
  (push только по запросу).
