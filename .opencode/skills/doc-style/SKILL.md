# Стандарт русской прозы для документов

Документы проекта читаются людьми. Пиши по-русски так, чтобы предложение читалось с первого раза
без знания внутреннего жаргона. Имена кода (типы, методы, флаги, `task-cache`, `View`) остаются
английскими; всё остальное — русскими словами.

## Когда применять

- Любая правка `specs/**`, `README.md`, `specs/decisions/**`, `specs/plans/**`, `specs/tools/**`.
- Составление нового документа любого типа.
- Ревью документального диффа (reviewer выносит замечания по этому же списку).

## Глоссарий: как называть вещи

Один факт — одно имя. Левая колонка — как писать; правая — от чего держаться подальше.

| Принято | Запрещено |
|--------|-----------|
| блокировка, мьютекс; «не беря блокировок» | лок, зал, «вне любых залов», «под одним залом» |
| слияние пачки (в таблицу), сброс буфера | флеш, батч-флеш, авто-флеш |
| вычитать канал до конца, дочитать | дренаж, дренировать |
| запись в таблицу; «префикс записывается» | эмиссия, эмится, эмиттить |
| разворачивает DFS, продолжает спуск | раскручивает, докручивает, докрутка |
| объединяется в одну запись | схлопывается |
| неизменяемый снимок для чтения (`View`), «опечатать таблицу» (`Seal`) | запечатанная ручка, хэндл |
| запускает горутины | спавнит |
| передаёт потоком | стримит |
| производитель, потребитель | продюсер, консьюмер |
| атомарный счётчик выданных задач; «снять индекс задачи» | курсор претензий, «претензии» |
| мемоизация; «таблица мемоизации» | мемо, «мемо раннего стопа», мемо-ридер |
| ранняя остановка счёта | ранний стоп |
| отсечение, отсекает | прунинг, прунит (пакет — `pruner`, это имя кода) |
| фильтр записей в кэш (`ADR-030`) | гейт записи |
| не сохраняет состояние | стейт-лесс |
| ничего не знает о предметной области | домен-свободный |
| вызов команды | инвокация |
| совпадает с паттерном; правило сопоставления | матчится, мэтчится, матчер |
| двоичный файл, утилита | бинарь |
| запас (памяти) сверх пика | headroom |
| противодавление канала | backpressure (один раз допустимо в скобках при определении) |
| конкуренция за блокировку | контентен |
| ограничение значения диапазоном | кламп, clamp'ы |
| партия задач, пакетная отправка | батч (в именах кода — как есть: `entryBatch`) |
| конвейер | пайплайн |
| проход по диапазону глубин | свип, свипать |
| объединение записей по маске | склейка |
| список работ (`worklist`) | варклист |
| промежуточный буфер записи (`Staging`) | стейджинг |
| отказ безопасен в сторону запрета | fail-closed (при первом употреблении — с пояснением) |

Исключения: устоявшиеся имена раздела, ставшие терминами проекта, — «гейты агентского пайплайна»
(`specs/gates.md`, G1–G12). Слово «гейт» при этом означает **только** их: не «память не гейт»,
не «гейт принятия» (пиши: «порог принятия»).

## Запрещённые обороты

- **Русские глаголы из английских и латинских корней**: «эмится», «прунит», «дедлокается»,
  «answering'ется», «гонятся доски». Есть естественный русский глагол — бери его.
- **Смешение кириллицы и латиницы внутри слова**: «stab-орбита» → «орбита стабилизатора»;
  «D4-эквивариантен» → «эквивариантен относительно D4»; «hit'ы» → «попадания»; «Staging'и» →
  «экземпляры `Staging`»; «lookup'ы» → «поиск по ключу».
- **Телеграфный стиль без сказуемого**: «память не гейт», «он же дефолт», «clamp считает counter —
  фазовая политика». У каждого предложения есть подлежащее и сказуемое.
- **Цепочки родительного падежа** (три и больше подряд): «дублирование дуала разреза обращённого
  тура» → глагольная конструкция: «разрез глубже половины клетки ничего нового не даёт: он
  повторяет уже рассмотренный двойственный разрез».
- **Скобочный шум**: более двух скобок или более двух ссылок `(ADR-…)` в одном предложении —
  ссылки в конец предложения, не больше одной–двух.
- **Кавычки-паразиты** для важности: «мёртвость», «живая таблица». Если слово требует кавычек —
  замени словом без кавычек или дай ему определение.

## Правила фразы и документа

- Предложение — одна мысль, ориентир ≤ 25 слов. Длинные объяснения разбивай на несколько
  предложений; тире не заменяет точку.
- Порядок в абзаце: зачем → что как делает → что будет, если сделать иначе.
- Новый термин при первом употреблении определяется одним предложением или ссылкой на спеку.
- Имена фаз конвейера — только `gen A`, `gen B` и count-фаза; всего три фазы (две генерационные
  и счёт). «Двухфазная генерация» допустима лишь как уточнение про `gen A`+`gen B`.
- Промежуточная таблица `gen A` — «промежуточная таблица»; второй экземпляр — task-cache. Других
  имён («аккумуляторы», «таблица классов») не вводить.
- Единицы: время — мс/мкс/с, память — МБ (и в тексте, и в заголовках таблиц; ГиБ/КиБ — нет).
  Исключение: протоколы исторических замеров в ADR — единицы и числа сохраняются ровно как записаны,
  конвертация меняет факт.
- Группа симметрий — `D4` (как в коде), не «D₄». Эвристика Warnsdorff — «эвристика Варнсдорффа».
- Числа из бенчмарков берутся из логов (`tools/bench_table.py`) и не меняются стилистически;
  правится только текст вокруг них.
- Кавычки русского текста — «ёлочки»; код, имена и флаги — в обратных кавычках.

## Проверка перед коммитом

```bash
# список запрещённых слов по всем документам (ожидается пустой вывод):
grep -rniE 'вне залов|под одним залом|в залах|флеш|дренир|дренаж|эмится|эмисс|раскруч|докруч|спавн|стримит|консьюмер|продюсер|прунит|прунинг|звукос|стейт-лесс|домен-свобод|инвокац|матчит|бинар[ьы]ш|headroom|backpressure|контентен|кламп|свип|варклист|ранний стоп|мемо[^и]|хэндл' specs/ README.md
```

Слова из списка легальны внутри имён кода в обратных кавычках (`Staging.Flush`) и в этом файле.
Кроме грепа — перечитать дифф целиком: grep не ловит телеграфию и цепочки родительных.
