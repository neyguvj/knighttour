# Переиспользуемые инструменты (`tools/`)

Агент перед скриптом сначала снимает индекс `specs/tools/README.md` и переиспользует
готовое. Одноразовый скрипт допустим только когда переиспользование вне текущей задачи
невозможно (завязан на уникальные артефакты задачи) — тогда он не попадает в `tools/`.

## Тул или одноразовый скрипт

- Переиспользуется вне задачи (парсинг логов, рендер таблиц, сверка чисел с эталоном,
  разбор worktree/bench-механики) → **тул**: `tools/<snake_case>.py` + карточка.
- Одноразовый → в `$TMPDIR` или `/tmp`, не в репозиторий; если оставил след в дереве —
  удали тем же коммитом/до отчёта.

## Конвенции тула

- **Python 3, только stdlib.** Никаких pip-зависимостей и `requirements.txt`.
- Запуск: `python3 tools/<name>.py <args>`; shebang `#!/usr/bin/env python3` обязателен.
- Docstring первой строкой — usage (как у `bench_table.py`); при неверных аргументах —
  печать usage и код выхода 1, без трейсбека.
- Переносимость darwin + linux: ловушки shell/юзерленда — AGENTS.md «Shell environment».
- Вывод — в stdout (для пайпов), ошибки — сообщение + ненулевой код.
- Make-обёртка — только если тул стал частью пайплайна (`check`/`bench*`, как
  `make bench-table LOG=…`); утилите одного агента обёртка не нужна.

## Карточка и индекс (то же изменение, что заводит тул)

Карточка `specs/tools/<tool>.md` — эталон текущего поведения, без истории:

```markdown
# <tool> — <одна строка назначения>

**Код:** [`tools/<tool>.py`](../../tools/<tool>.py) · **Запуск:** `python3 tools/<tool>.py <args>`

## Назначение
<что делает и кто потребитель (README/ADR/агент)>

## Интерфейс
<аргументы, формат входа, формат выхода; ошибки>

## Поведение и ограничения
<нормализации, порядок вывода, границы; зависимости>
```

Строка в индекс `specs/tools/README.md` (таблица: Тул | Путь | Назначение | Когда звать)
обязательна тем же изменением. Удаление тула — удаление карточки и строки индекса.

## Проверка

CI python не покрывает (`make check` — только Go): прогони тул вручную на реальном входе
до отчёта; для изменения существующего — убедись, что старый формат входа не сломан.
