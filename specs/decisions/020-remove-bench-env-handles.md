# ADR-020. Удаление env-хендлов бенч-харнесса: дефолты фиксированы, гейты — в Makefile

## Статус
Принято

## Контекст
В харнессе накопилось семь переменных окружения: гейты размеров `BENCH_DEEP` / `BENCH_8X8`,
оверрайд глубин `BENCH_DEPTHS`, ручки тюнинга count-фазы `BENCH_COUNT_K/B/C` и порядок снятий
`BENCH_COUNT_ORDER`. Ручки отработали назначение: K=10000, B=16 — измеренный оптимум свода
ADR-019 (план 13), C=4 зафиксирован фиксом механики, LIFO/FIFO-контраст закрыт как **TIE**
(план 13, 2026-09-16). Гейты и оверрайды держат в Go-коде SKIP-логику и просачиваются в спеки.
Решение пользователя — оставить в коде только дефолтное поведение.

## Решение
- `counter/benchmark_test.go`: все `os.Getenv` удалены — гейты (`deepEnvVar`/`sizeEnvVars`/
  `gatedSizes`/`gateVar`), оверрайд глубин (`benchDepthsEnv`; `sweepDepths` отдаёт только
  descending до `depthFloors`, безусловный in-code cap `sweepDefaults` удалён — он глушил явные
  точные глубины вне набора) и ручки диспатча
  (`applyDispatchKnobs`/`applyPositiveEnv`/`applyOrderEnv`).
- Тюнинг count-фазы — фиксированные дефолты K=10000, B=16, C=4 (значения свода ADR-019);
  рантайм-оверрайдов нет.
- FIFO-ветка снятий удалена как мёртвый код (`dispatchClaimFIFO`, fifo-параметр стека): контракт
  один — LIFO; контрастная точка закрыта TIE, её числа остаются в плане 13.
- Гейты и точечные прогоны переезжают в слой Makefile через `-bench`-фильтры: `make bench` →
  `…/size[56]`, `make bench-deep` → `…/size[567]`, `make bench-8x8` → `…/size8`; `DEPTHS=a,b` —
  чистый make-аргумент, транслируемый в якорированный `-bench='…/sizeN/^depth(a|b)$'` (сегменты
  матчатся регуляркой без привязки к краям — без якорей точка `1` подобрала бы depth10–19).
  Cap 8×8 `{32,30}` — default-фильтр size8-целей только при отсутствии `DEPTHS`; явный `DEPTHS`
  подбирает свою точку всегда. Go-код о гейтах не знает.
- Сохранён внутренний тест-сигнал `PEAKRSS_CHILD` (`TestPeakRSSUnits`, re-exec свежего процесса):
  это не ручка тюнинга, человеком не выставляется.

## Последствия
- Прямой `go test -bench=.` гоняет все доски (часы/дни) — защита SKIP'ом снята, примеры фильтров
  документируются в `specs/benchmarks.md`.
- Валидация глубин превращается в «нет совпадений — ничего не запустилось» вместо SKIP/Fail с
  сообщением; несуществующий `DEPTHS` молча не запускает подтесты.
- Свип K/B/C без правки кода невозможен; при новом исследовании ручку заводят временно и удаляют
  по завершении (прецедент — заметка ADR-014 о `BENCH_GC_PERCENT`).
- Тестам, мутировавшим пакетные переменные швов, нужны явные аргументы/швы формулы `Beff` и
  ёмкости стека (реализация — за кодером); кейсы FIFO из тестов исчезают вместе с веткой.

## Замеры
n/a — чистка харнесса: конвейер и дефолты не меняются, значения K/B/C перенесены из свода ADR-019
без изменений, тайминги/память идентичны по построению.
