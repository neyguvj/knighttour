# ADR-009. Отклонённые эвристики поиска: цветовой прунинг, Warnsdorff-порядок, endpoint-mismatch

## Статус

Отклонено (замерено, не реализовано / реализовано и выключено). Записано, чтобы не
переисследовать.

## Контекст

Кандидаты на ускорение DFS/DP, проверенные на 5×5/6×6 в рамках планов 02/04.

## Решение и замеры

### Цветовой (бипартитный) прунинг — отклонён

Гипотеза: на нечётных досках конь чередует цвет, счётчик цветов даёт необходимое
условие. **Замер: 0 срабатываний** — инвариант выполняется автоматически вдоль любого
DFS-пути; старты нужного чёта уже фильтрует `graph.SholdSkip`. Код не заведён.

### Warnsdorff-порядок кандидатов — отклонён

Гипотеза: обход соседей по возрастанию степени сокращает дерево. **Замер: число узлов
не меняется, время +10–20%** (пересортировка на горячем пути не окупается; для задачи
полного перебора порядок не влияет на число листьев). Соседи остаются в фиксированном
порядке `possibleMoves`.

### Endpoint-mismatch фильтр (план 02, проверка A) — выключен

Гипотеза: если у `G[shape]` ровно два degree-1 вершины `{a,b}`, то конец `end ∉ {a,b}`
даёт ноль. **Замер: 0 срабатываний сверх корневого L1** — если A убивает конец, deg-1
вершины остаются deg≤1 и в `G[shape∖{end}]`, их режет тот же корневой прунер. Механизм
в `ShapeFeasible` оставлен (`L2Endpoints`), по умолчанию выключен — только для инструментов
этапа 0.

## Последствия

Ни одна из трёх эвристик не донесла выигрыша; домены зафиксированы, повторное
исследование требует новых данных.
