# ADR-001. Class mode: подсчёт через классы форм вместо мемо-таблицы и reversal

## Статус

Принято. Открытые вопросы: память M (план 01), гипотеза возврата reversal (план 06).

## Контекст

Oracle-подход мемоизировал `h(U,u)` таблицей классов и обращением тура
(prefix-cache reversal). Замер oracle на стенде 6×6 d18: ~250k записей, ~87% —
нули, повторная обращаемость классов всего ×1.16: таблица почти не
переиспользуется, но занимает память и требует локов в хот-патте. Reversal
страдал пограничной проблемой (дополнение не коммутирует с трансляцией) и
связывал глубину условием `2p ≤ totalCells`.

## Решение

Убрать мемо-таблицу совсем. Идентичность перегруппировки:

```
total = Σ_листьев(T,t) weight(T,t) · Σ_{u ∈ N(t)∩U} h(U,u)
      = Σ_классам C   h(C) · M(C),        U = full \ T,
M(C)  = Σ weight(листа) по листьям, чья пара (U,u) нормализуется в C.
```

Каждый класс вычисляется DP ровно один раз на финальном проходе; размещения
учтены тем, что M накапливается по фактическим листьям генерации. Ограничение
`2p ≤ totalCells` снято. Пайплайн: gen A → gen B → counting (`specs/counter.md`).

## Последствия

- Плюсы: нет мемо-таблицы и reversal-локов в горячем DFS; нули h не хранятся;
  корректность — точная перегруппировка без допущений.
- Минусы: одна запись M на каждый опрошенный класс (память растёт с глубиной,
  отсюда потолок `size²/2`); время на 7×7 d22 пока хуже reversal (см. замеры) —
  оптимизация вынесена в планы 01/05/06.

## Замеры

Oracle-статистика (6×6 d18): ~250k классов, ~87% нули, переиспользование ×1.16.

Class mode vs reversal (git `0d142f4`), Apple M4 Max, 14 ядер, 7×7 d22:

| метрика | class mode | reversal |
|---|---|---|
| время прогона | 596 с | 252 с |
| пик RSS | **23.46 ГБ** | 9.60 ГБ |
| gen B | 224.6 с, writes 3 591 773 354 | 141 с, writes 1 397 913 888 |
| counting | 371 с | 107.9 с |
| записей в хранилище | 284 359 145 классов | 131 814 325 задач |

Дерево поиска идентично (разбивка прунинга gen B совпадает счёт в счёт) — разрыв
объяснён представлением M и финальным проходом (план 01).
