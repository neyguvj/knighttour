# ADR-005. Единый ключ `path.Path(state,end)`; `start` вне ключа; `ShapeKey` удалён

## Статус

Принято.

## Контекст

Исторически ключ хранилища включал `start`, а класс формы имел отдельный тип
`ShapeKey`. Число продолжений маршрута зависит только от посещённой маски и текущей
клетки, но не от того, откуда в маску пришли.

## Решение

Единственный ключ всех аккумуляторов — `path.Path`: неизменяемая компарировая пара
`(state state.State, end uint8)`. `start` в ключ **не входит** и в канонизацию D4 не
входит: симметричные пары `(state, end)` эквивалентны полностью.

- Ген A: ключ — D4-каноническое размещение префикса `Canonicalize(state,end)`.
- Ген B / M: ключ — нормализованная форма дополнения `KeyFromPrepared(ctx,u)`
  (D4 ⋉ трансляции). Тип — тот же `path.Path`; отдельный `ShapeKey` удалён как
  структурный дубликат.

## Последствия

- Одна типобезопасная сущность кочует между searcher → cache → shapecount → counter.
- Убрана LUT `bestIdx` для пар `(start,end)`: канонизация пары — перебор 8 преобразований.
- Размер bbox ≤ N×N ⇒ нормализованная маска помещается в `uint64` при N ≤ 8.
