# Решения (ADRs)

Сюда вынесены **принятые решения с обоснованием и замерами**. Модульные спеки
ссылаются на ADR одной строкой и не пересказывают историю/бенчмарки.

Правило: одно решение = один файл `NNN-<slug>.md`. Формат — шаблон
`spec-writing` skill (Контекст → Решение → Последствия → Замеры → Ссылки).
Замеры фиксируются **навсегда**: каждое новое решение несёт свои числа до/после.
