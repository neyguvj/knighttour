# Решения (ADR)

Здесь собраны **принятые решения с обоснованием и замерами**. Модульные спеки ссылаются
на ADR одной строкой и не пересказывают историю или бенчмарки.

Правило: одно решение — один файл `NNN-<slug>.md`. Формат — шаблон скилла `spec-writing`
(Контекст → Решение → Последствия → Замеры → Ссылки). Замеры фиксируются **навсегда**:
каждое новое решение несёт свои числа до/после.
