# shapecount: DP числа ходов по классу формы

## Ответственность

Вычисляет `h(shape, ends)` — число гамильтовых путей коня внутри маски-формы с заданными
концами — DP-перечислением с мемо. Финальный проход class mode (ADR-001): каждый класс
считается ровно один раз, мемо-таблица между классами не нужна.

## Публичный API

```go
const DefaultShapeFilter = pruner.L2ForcedChain   // pre-DP фильтр по умолчанию (ADR-008)

func New(g *graph.Graph) *Counter
func (c *Counter) SetShapeFilter(mask pruner.L2Checks)      // L2None выключает фильтр
func (c *Counter) SetL2(mask pruner.L2Checks, minTodo int)  // конфигурация DP-прунеров L2

// h по форме для нескольких концов; одно мемо на все концы одной формы.
// res (nil допустим) копит статистику прунинга/фильтра/DP.
func (c *Counter) CountShape(shape state.State, ends []int, res *types.Result) []uint64

// + необязательный persistent tail-мемо между вызовами одного воркера (nil = выключен).
func (c *Counter) CountShapeWithTail(shape state.State, ends []int, res *types.Result, tail *TailMemo) []uint64

// Tail-мемо (план 03): таблица f(cur,todo), живущая между формами одного воркера.
func (c *Counter) NewTail() *TailMemo
func (t *TailMemo) Entries() int
func (c *Counter) SetTailMemo(k, slots int)   // k = max popcount(todo) для записи; 0 = off
```

## Как считается h

- DP `f(cur, todo)` с мемо на подзадачи; **одно мемо на все концы одной формы** (подзадачи
  `(cur,todo)` общие). Прунер — тот же `ShouldPruneAfterVisit` (+ L2 при включении),
  корректен на нормализованных координатах по инвариантности смежности.
- **Мемо-буфер** — переиспользуемая таблица открытой адресации из `sync.Pool`: плоские
  массивы `keys/curs/vals/stamps`, линейная пробировка, load factor ≤ ½, рост удвоением;
  инкремент поколения делает таблицу логически пустой за O(1) (это не «состояние между
  вызовами»). Хэш ключа `(todo,cur)` — финализатор murmur3.
- **Shape-фильтр** (ADR-008): до выделения memo каждый конец прогоняется через
  `Pruner.ShapeFeasible`; отсечённый конец → `h=0`, если отсечены все — нулевой срез без
  memo, `res.FilteredShapes++`.
- **Tail-мемо** (план 03): ключ точный `(todo,cur)` в нормализованных координатах без
  канонизации; пишутся/читаются только записи `popcount(todo) ≤ K`; открытая адресация без
  штампов (`todo==0` = пустой слот), рост до `capSlots`, переполнение лишь теряет потенциал.
  Одна таблица на воркера — без локов.

## Инварианты

- Итог `Σ h(C)·M(C)` инвариантен к фильтру и L2: они дают только доказуемые нули.
- Значение пары `(cur,todo)` зависит только от индуцированного подграфа `G[todo∪{cur}]` с
  отмеченным `cur` — совпадение ключа между формами гарантирует совпадение значения
  (обоснование переиспользования tail-мемо).
- `CountShapeWithTail(..., nil)` побитово идентичен `CountShape`.

## Ограничения и edge cases

- Нулевые h-формы дёшевы: прунер отсекает в корне DP.
- `h({u}, u) == 1` (одна клетка — вырожденный путь).

## Тесты

`shapecount/shapecount_test.go`: исчерпывающее сравнение с брутфорсом на малых и случайных
связных масках (в т.ч. многоконцевой вызов с общим мемо); нули и «чужой» конец; статистика
прунинга; переиспользование memo; эквивалентность tail-мемо (общий `tail` == свежий прогон,
`TailHits>0` на пересекающихся формах); эквивалентность L2; фильтр — табличные кейсы и
звуковость против `bruteForceH`. Замеры фильтра/L2 — ADR-007/008.
