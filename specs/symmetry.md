# symmetry: симметрии доски (D4) и канонизация

## Ответственность

Пакет строит группу симметрий квадрата D4 и приводит размещения к канонической форме, чтобы
сократить повторяющуюся работу поиска. Он даёт два продукта: канонические стартовые группы с
размерами орбит и канонизацию размещения `(маска, конец)` в форму «каноническая маска + класс
конца». Писатель и читатель таблицы кэша вызывают одни и те же функции (specs/cache.md).

Пакет не хранит весов и ничего не знает о таблицах: он возвращает `K`, тег класса `rep` и
`orbitSize`, а применяет их вызывающий код как есть. Горячий путь делает только подстановки в
заранее построенные таблицы `perms` и `compose` — без замыканий, аллокаций и рекурсии.

## Группа D4 (8 преобразований)

| № | Название | Формула (x,y) |
|---|----------|---------------|
| 0 | Identity | (x, y) |
| 1 | Rotate 90° | (y, size-1-x) |
| 2 | Rotate 180° | (size-1-x, size-1-y) |
| 3 | Rotate 270° | (size-1-y, x) |
| 4 | Flip horizontal | (x, size-1-y) |
| 5 | Flip vertical | (size-1-x, y) |
| 6 | Flip diag1 | (y, x) |
| 7 | Flip diag2 | (size-1-y, size-1-x) |

## Каноническая форма пары `(маска, конец)`

Маску сводят к канонической: `K = min_t t(маска)` — наименьшая из восьми картин маски. Внутри
`K` выбирают класс конца: два конца одной маски считают эквивалентными, если некоторое
преобразование, фиксирующее `K`, переводит один конец в другой. Такие преобразования образуют
стабилизатор `Stab(K) = {t ∈ D4 : t(K) = K}`.

Пара `(K, rep)` равна лексикографическому минимуму пар `(t(маска), t(конец))` по всем восьми
преобразованиям. При нетривиальном стабилизаторе минимум маски достигается сразу несколькими
преобразованиями. Неоднозначности не возникает: конец приводят к репрезентанту его орбиты при
стабилизаторе, и результат не зависит от того, какое именно преобразование достигло минимума.

Число продолжений `h` и размер орбиты пары постоянны внутри класса эквивалентности:

`orbitSize = |D4·(K, e)| = 8 / |Stab(K, e)|`

Здесь `Stab(K, e)` — множество преобразований, фиксирующих одновременно маску и конец. Размер
`orbitSize` вычисляют из таблицы `perms` при чтении; нигде пакет его не хранит.

## Публичный API

```go
const NumTransforms = 8 // число элементов группы D4

// Transform переносит клетку (x, y) данным преобразованием D4 для доски указанного размера.
// Замыкания вызываются только при построении таблицы perms.
type Transform func(x, y, size int) (int, int)

func GetSymmetries() []Transform // 8 замыканий в порядке таблицы выше

// CanonicalGroup — одна орбита клеток: её члены, минимальный представитель и размер.
type CanonicalGroup struct {
    Positions []int
    Canonical int
    OrbitSize int
}

// NewSymmetry строит таблицы перестановок для доски size×size вместе с каноническими
// позициями клеток, размерами их орбит и стартовыми группами.
func NewSymmetry(size int) *Symmetry

// Позиции и орбиты клеток доски (стартовые группы).
func (s *Symmetry) GetCanonicalPosition(pos int) int       // наименьшая клетка орбиты pos
func (s *Symmetry) IsCanonicalPosition(pos int) bool       // pos — минимум своей орбиты
func (s *Symmetry) GetOrbitSize(pos int) int               // размер орбиты клетки pos
func (s *Symmetry) GetCanonicalGroups() []CanonicalGroup   // орбиты, отсортированные по канону

// CanonicalMaskFrame — каноническая маска и её стабилизатор. K = min_t t(st); frame — номер
// преобразования, достигшего минимума, детерминированно наименьший из них; stab — битовая
// маска Stab(K): бит i означает, что преобразование i фиксирует K. Множество stab содержит
// тождество и замкнуто относительно композиции, то есть является подгруппой. Набор
// {t : t(st) == K} — это смежный класс {s∘frame : s ∈ Stab(K)}.
func (s *Symmetry) CanonicalMaskFrame(st state.State) (K state.State, frame uint8, stab uint8)

// TransformCell — образ клетки при преобразовании t (подстановка в perms); переводит конец
// из системы координат st в систему координат K.
func (s *Symmetry) TransformCell(t uint8, cell int) int

// ClassRep — репрезентант класса клетки: минимум её орбиты {s(cell) : s ∈ stab}. Идемпотентен.
// Тип uint8 — поле rep:8 упакованного значения таблицы кэша (specs/cache.md).
func (s *Symmetry) ClassRep(stab uint8, cell int) uint8

// CellOrbitSize — размер орбиты пары (K, cell) в группе D4: 8 / |{s ∈ stab : s(cell) == cell}|.
// Постоянен на классе клетки.
func (s *Symmetry) CellOrbitSize(stab uint8, cell int) int

// CanonicalClass — канонизация, общая для писателя и читателя: каноническая маска, тег класса
// конца и размер орбиты пары. Композиция CanonicalMaskFrame → TransformCell(frame, end) →
// ClassRep/CellOrbitSize; результат не зависит от того, какой минимизирующий кадр выбран.
func (s *Symmetry) CanonicalClass(st state.State, end int) (K state.State, rep uint8, orbitSize int)
```

Когда для одной маски обрабатывают много концов, `CanonicalMaskFrame` вызывают один раз, а на
каждый конец добавляют лишь `TransformCell(frame, ·)` и `ClassRep` / `CellOrbitSize`. Одиночное
размещение канонизуют через `CanonicalClass`. Писатель и читатель вызывают одни и те же
функции, поэтому рассогласовать канонические формы по построению невозможно.

## Инварианты

- `(K, int(rep))` равен лексикографическому минимуму пар `(t(st), t(end))` по D4, а `orbitSize`
  равен числу различных таких пар. Результат `CanonicalClass` инвариантен вдоль орбиты: для
  любой `g ∈ D4` он одинаков на входах `(g·st, g·end)`.
- Пары `(K, e)` и `(K, e')` лежат в одном классе тогда и только тогда, когда некоторый
  `s ∈ Stab(K)` переводит `e` в `e'`. На классе постоянны `rep`, число продолжений `h` и
  `orbitSize`: стабилизаторы связанных концов сопряжены в D4, поэтому равны по мощности.
- `stab` из `CanonicalMaskFrame` — подгруппа преобразований, фиксирующих `K`. Если стабилизатор
  тривиален (`stab == 1<<0`), то `ClassRep` возвращает клетку без изменения, а
  `CellOrbitSize` даёт 8.
- `start` в канонизации не участвует: число продолжений зависит только от маски и конца
  (ADR-005).
- Горячий путь (`CanonicalMaskFrame`, `TransformCell`, `ClassRep`, `CellOrbitSize`,
  `CanonicalClass`) использует только таблицы `perms` и `compose`; таблица индексов композиции
  `compose` строится вместе с `perms`. Замыкания `Transform` вызываются ровно один раз — при
  построении таблиц.

## Ограничения и edge cases

- Центр нечётной доски: его орбита состоит из одной клетки, и весь D4 его фиксирует. Поэтому при
  любой маске, содержащей центр, класс конца-центра — одиночный, а `CellOrbitSize` считает
  орбиту пары через стабилизатор маски.
- `CanonicalClass` и `ClassRep` корректны для любого индекса клетки; контракт конвейера требует
  `end ∈ st`, и за это отвечает вызывающий код.
- Клеток на доске не больше 8×8, поэтому их индексы меньше 64: восьмубитного тега `rep` в
  упакованном значении таблицы достаточно (specs/cache.md).
- `CellOrbitSize` возвращает степень двойки из `{1, 2, 4, 8}`, поэтому деление накопленного веса
  класса на него даёт целое без остатка (математика ADR-011).

## Тесты

`symmetry/symmetry_test.go` покрывает орбиты клеток и стартовые группы:

- `TestNewSymmetry`, `TestMultipleSizes` — для размеров 5–8 таблицы построены, а группы покрывают
  всю доску;
- `TestGetSymmetries` — возвращается ровно 8 преобразований;
- `TestApplyTransformStatic` — формулы замыканий: повороты угла на 90°/180°/270°, два поворота
  на 90° равны повороту на 180°;
- `TestApplyTransform`, `TestPropertyTransformInvolutions` — образы углов, рёбер и диагоналей;
  отражения и поворот на 180° — инволюции;
- `TestGetCanonicalPosition`, `TestIsCanonicalPosition`, `TestGetOrbitSize` — углы, рёбра,
  диагонали и центр; размеры орбит в диапазоне [1,8];
- `TestGetCanonicalGroups`, `TestPropertyOrbitSizePlus` — группы покрывают доску, позиции в них
  отсортированы, у группы единый канон и согласованный размер;
- `TestApplyTransformToStateWithLookup` — тождественное преобразование сохраняет маску, другие
  переставляют посещённые клетки.

`symmetry/canonical_test.go` покрывает контрактное ядро канонизации на случайных масках с
фиксированным seed:

- `TestCanonicalMaskFrame` — `K` равна brute-force минимуму образов, `frame` — наименьший индекс
  из достигших минимума; `stab` совпадает с множеством `{t : t(K) == K}` и является подгруппой;
- `TestCanonicalMaskFrameArgminIndependence` — для всех минимизирующих кадров последующий
  результат (`ClassRep` и `CellOrbitSize` от конца в системе координат K) одинаков;
- `TestClassRep` — идемпотентность, `rep ≤ cell`, равенство репрезентантов тогда и только тогда,
  когда клетки связаны стабилизатором;
- `TestCellOrbitSize` — постоянен на классе, совпадает с brute-force числом различных пар
  `(t(st), t(end))`, лежит в `{1, 2, 4, 8}`; при тривиальном стабилизаторе равен 8;
- `TestCanonicalClassMatchesBruteForce` — табличные случайные маски досок 5×5–8×8: совпадение с
  лексимимумом пары и числом различных пар, совпадение с композицией пути через кадр,
  инвариантность вдоль орбиты при любом `g ∈ D4`;
- `TestCenterCellClassSingleton` — центр нечётной доски: тег класса принадлежит только ему на
  всех клетках доски, а орбита пары равна орбите маски; детерминированная таблица без seed.
