# split: ценз счёта туров разрезом доски пополам со склейкой по связности

> **Статус: измерительный инструмент (план 26 закрыт, ADR-043 «отклонено»).** Спека эталонна
> для пакета как инструмента ценза: standalone движок половинного frontier DP со склейкой по
> связности плюс бенчмарк `BenchmarkSplitCensus`. Пакет не импортируется в конвейер подсчёта
> (`counter`) и CLI; направление счёта 8×8 разрезом пополам закрыто числами ADR-043, инструмент
> остаётся.

## Ответственность

Считает гамильтоновы пути (`Paths`) и циклы (`Cycles`) доски N×N разрезом пополам: половины
обрабатываются независимыми послойными frontier-DP, каждая до интерфейсных состояний σ (использованные
рёбра шва, спаривание их пеньков фрагментами пути, число глобальных концов), итог — сумма произведений
N_L(σ)·N_R(σ̄) по совместимым состояниям со связностью, проверяемой композицией спариваний (формализм σ —
план 26). Публично отдаёт итог и снимок метрик ценза: число достижимых σ, послойный пик состояний,
объём склейки.

Пакет НЕ делает: интеграции с CLI и конвейером reversal, параллелизма (счёт однопоточный и
детерминированный), подбора нестандартных разрезов (зигзаг не заводится по числам ADR-043),
отсечений сверх точного кодирования состояний.

## Публичный API

```go
type Family int

const (
    Paths  Family // гамильтоновы пути: степени ≤ 2, связно, ровно две вершины степени 1
    Cycles Family // гамильтоновы циклы: все степени 2
)

// Variant — вариант геометрии шва для сравнения цензом.
type Variant int

const (
    Straight Variant // прямой сбалансированный вертикальный разрез c = ⌈n/2⌉
    Mirror   Variant // он же с D4-сжатием: одна таблица на обе половины; только чётные n
)

// ErrOverCap — сигнал, что построение превысило мягкий байтовый потолок и остановлено.
// Проверка errors.Is; счётчики момента обрыва — в OverCapError.
var ErrOverCap error

// OverCapError — ошибка обрыва: Layer — слой DP половины, States — живые состояния таблицы,
// Bytes — зарезервированные байты структур построения, Cap — снимок потолка на момент остановки.
type OverCapError struct{ Layer, States, Bytes, Cap int }

// Count считает туры доски n×n разрезом пополам сбалансированным вертикальным разрезом.
// Невалидный вход (неизвестный fam, непригодная n) — ошибка; превышение потолка — OverCapError, не OOM.
func Count(n int, fam Family) (uint64, error)

// Census — снимок метрик прогона: SigmaL/SigmaR — число достижимых интерфейсных состояний σ по
// половинам; LayerPeak — максимум живых состояний DP по слоям и половинам; Joins — число пар одной
// группы по S, проверенных на склейке; MaxWeight — максимальный вес состояния.
type Census struct {
    SigmaL, SigmaR int
    LayerPeak      int
    Joins          uint64
    MaxWeight      uint64
}

// CountWithCensus — тот же счёт с явным вариантом разреза и снимком ценза.
func CountWithCensus(n int, fam Family, v Variant) (uint64, Census, error)
```

Мягкий потолок — внутренний рычаг пакета в зарезервированных байтах структур построения (таблицы
поколений DP и таблицы σ); значение по умолчанию калибруется числами ценза под бюджет машины. Тесты
изменяют рычаг напрямую; ручек окружения и флагов нет (ADR-020).

## Инварианты

- Интерфейсное состояние половины σ = (S, M, ε): S — использованные рёбра шва, M — совершенное
  спаривание пеньков S и локальных глобальных концов фрагментами пути внутри половины, ε ∈ {0,1,2} —
  число глобальных концов в половине; величина |S| + ε чётна. Фрагменты покрывают половину дизъюнктными
  путями, преждевременный цикл запрещён.
- Итог ровно равен числу множеств рёбер графа коня, образующих гамильтонов путь (`Paths`) или цикл
  (`Cycles`): половины разделяют одно S, для `Paths` совместимость требует ε_L + ε_R = 2, а объединение
  — единственный путь/цикл тогда и только тогда, когда вспомогательный граф G_σ (вершины — рёбра S и два
  маркера глобальных концов, рёбра — пары спариваний M_L и M_R) связен.
- Конвенция счёта: множества рёбер, каждый тур один раз независимо от направления; сравнение с
  направленными эталонами — умножением на 2 для обоих семейств (конвенция планов 07 и 23).
- Детерминизм: фиксированные n, fam, Variant дают одинаковые итог и все счётчики `Census` между
  прогонами и процессами; плавает только wall-время. Счёт однопоточный.
- Для чётных n и `Mirror` таблица строится один раз и переиспользуется с отражением σ:
  N_R(σ) = N_L(ρσ); итог совпадает со `Straight` (закреплено тестом).
- Рост таблиц поколений DP и таблиц σ проверяется суммарными байтами до аллокации; превышение
  возвращает `OverCapError` со счётчиками прогресса до исчерпания памяти процесса. Производные
  структуры фазы склейки (записи декодированных σ, арена пар, индексы групп) отдельно не
  учитываются: их размер на запись того же порядка, что у учтённых σ-таблиц обеих половин, и
  ограничен малым кратным от них.
- Веса состояний — точный uint64 без насыщения; переполнение в рантайме не проверяется: вес состояния
  половины считает полуконфигурации и не ограничен сверху итогом доски. Свидетельство достаточности —
  `Census.MaxWeight` и жёсткая сверка итога с эталонами.

## Ограничения и edge cases

- Диапазон применения — доски 5×5–8×8; шов сбалансированного разреза содержит ровно 6n−8 рёбер
  (22/28/34/40). На меньших досках ядро корректно и проверяется тестами-оракулами.
- Нечётные n: половины несравненны (⌈n/2⌉ и ⌊n/2⌋ колонок), `Mirror` возвращает ошибку; таблицы
  строятся две.
- `Cycles` на нечётных n: семейство пусто (двудольный граф с разными долями), итог 0 без специального
  шортката — построение приходит к нулю само.
- Пустая таблица σ половины → итог 0 (процесс жив, это не ошибка).
- Заниженный потолок обрывает прогон `OverCapError` с прогрессом; остальные точки прогоняются.

## Тесты

- Оракул на малых досках (табличные): итог точно совпадает с независимым DFS-перебором гамильтоновых
  путей и циклов, реализованным в тестах пакета.
- Сверка с эталонами `docs/requirements.md`: 5×5 `Paths × 2 = 1728`, `Cycles × 2 = 0`; 6×6
  `Cycles × 2 = 19 724` — в юнит-бюджете `-race`. Точка 6×6 `Paths` в память стенда не помещается:
  при дефолтном рычаге она обрывается ошибкой `ErrOverCap` и публикуется как SKIP со счётчиками
   прогресса. Измеренный якорь обрыва и статус сверки эталона `6 637 920` — в ADR-043;
  бенчмарк сверяет итог с эталоном на любом прогоне, который дошёл до склейки.
- Тождество вариантов: `Mirror` и `Straight` на чётных досках дают равные итоги; |Σ| половин
  совпадают с точностью до обмена L/R.
- Детерминизм: два прогона одного входа — одинаковые итог и все поля `Census`.
- Потолок: заниженный рычаг даёт `ErrOverCap` со счётчиками момента обрыва (`Layer`, `States`,
  `Bytes`) и снимком потолка (`Cap`); процесс жив.
- Геометрия разреза: шов сбалансированного разреза — ровно 6n−8 рёбер; нумерация пеньков — биекция
  концов шва каждой половины; отражение ρ для чётных n переводит σ в σ той же доски.
