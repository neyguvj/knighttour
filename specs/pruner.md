# pruner: отсечение тупиковых ветвей

## Ответственность

`Pruner` проверяет необходимые условия и отсекает ветви DFS, которые заведомо не приведут
к полному туру. Он же работает фильтром записей в кэш на листьях генерационного спуска:
состояние с нулевым числом дополнений не попадает в таблицу. Реализация — один тип
`Pruner` (ADR-006). Статистику он не ведёт: метод возвращает причину отсечения, а учитывает
её вызывающий через `types.Result`.

## Ярусы проверок

- **L0 — локальный тупик**: за O(deg(last)) проверяет, не осталась ли среди соседей `last`
  изолированная клетка. Это дешёвая первая ступень отсечения.
- **L1 — глобальные проверки** (`globalCheck`, выполняются всегда при |unvisited| > 1):
  у `last` нет продолжения; `G[unvisited]` распадается на несколько компонент
  (flood-fill по битовой маске); эвристика концов гамильтова пути — вершины степени 1
  обязаны стать концами пути.
- **L2 — фильтр записей в кэш** (`ShouldPruneState`, только на листьях генерационного
  спуска, specs/searcher.md): проверяет необходимое условие существования гамильтова пути
  из `cur`, покрывающего `todo`, в графе `H = G[todo ∪ {cur}]`. Принята одна проверка —
  `ForcedChain` (ADR-030): union-find обязательных рёбер вершин степени 2.

`ForcedChain` корректна только при зафиксированном конце пути: в `todo` должна быть ровно
одна вершина степени 1 в `H`. Без этого условия проверка пропускается. Отсечение происходит,
когда обязательных рёбер у вершины больше, чем допускает путь (более двух в `todo`, более
одного у `cur`), или когда они образуют цикл.

Набор проверок закрыт (ADR-030): переключателей времени выполнения, масок и порогов нет
(ADR-020). Остаток на листе постоянен (`totalCells − depth`), поэтому экономить проверку
на мелких остатках не от чего.

## Публичный API

```go
// Reason — причина отсечения; счёт ведёт вызывающий.
type Reason uint8

const (
	NoReason       Reason = iota // ветвь не отсечена
	DeadEnd                      // локальный тупик: изолированная или недостижимая одинокая клетка
	NoContinuation               // у last нет непосещённых соседей
	Disconnected                 // G[unvisited] не связен
	Endpoints                    // нарушена эвристика концов гамильтова пути
	ForcedChain                  // обязательные рёбра требуют от вершины больше степеней, чем даёт путь, или образуют цикл
)

// New создаёт Pruner: проверки L0/L1 всегда включены, фильтр записей — ForcedChain.
func New(g *graph.Graph) *Pruner

// ShouldPruneAfterVisit — горячий метод DFS: вызывается сразу после посещения last.
// Возвращает флаг отсечения и первую сработавшую причину (NoReason, если не отсечено).
// Инвариант: посещение last могло изолировать только соседей last.
func (p *Pruner) ShouldPruneAfterVisit(last int, unvisited state.State) (bool, Reason)

// ShouldPruneState — фильтр записей в кэш на листе спуска: необходимое условие
// существования гамильтова пути из cur, покрывающего todo. Причина одна — ForcedChain;
// L0/L1 внутри не повторяются: вызывающий уже пропустил пару через
// ShouldPruneAfterVisit на спуске родителя (specs/searcher.md).
func (p *Pruner) ShouldPruneState(cur int, todo state.State) (bool, Reason)
```

## Алгоритм `ShouldPruneAfterVisit` (дешёвое сначала)

1. нет непосещённых клеток → `(false, NoReason)`;
2. осталась одна клетка: отсечь (`DeadEnd`), если она не соседняя к `last`;
3. локальный тупик среди соседей `last` → `DeadEnd`;
4. `globalCheck` (при |unvisited| > 1): `NoContinuation`, `Disconnected`, `Endpoints`.

Flood-fill внутри `globalCheck` тоже может заметить изолированную вершину и вернуть
`DeadEnd`, хотя обычно локальная проверка опережает его.

Маски соседей не копируются: `GetNeighborMask` читает предвычисленную маску за O(1).

## Инварианты и корректность

- Ни одна проверка (L0/L1/L2) не отсекает ветвь или ключ с ненулевым числом дополнений.
  Каждая проверка — необходимое условие: связность обязательна, а эвристика концов и
  обязательные цепочки следуют из существования гамильтова пути с началом в `cur`.
  Безопасность применения L2 как фильтра записей — лемма в specs/searcher.md.
- Все ярусы зависят только от структуры графа и маски, поэтому предикат эквивариантен
  относительно `D4` и согласован с канонизацией ключа: отсутствие дополнений — свойство
  орбиты, а не отдельного состояния.
- `Pruner` не хранит состояние и безопасен для конкурентных вызовов из воркеров; счётчики
  ведёт `types.Result.CountPrune(reason)`.
- `ForcedChain` стоит O(V+E), где V = |todo|+1 ≤ 64, и не делает аллокаций: вспомогательный
  union-find живёт в фиксированных `[64]`-массивах на стеке вызова.

## Ограничения и edge cases

- При |unvisited| ≤ 1 глобальная проверка не выполняется: одинокая соседняя клетка — это
  завершающий ход, а не тупик.
- Вырожденные остатки (|todo| ≤ 3) проверяются на общих основаниях. Сработавшее отсечение
  там так же безопасно (число дополнений равно нулю), а достижимые остатки остаются живы.
- `ShouldPruneState` намеренно не повторяет L0/L1: вызов идёт только на листе, чья пара уже
  прошла `ShouldPruneAfterVisit`. Связность `H` фильтру записей не требуется: его условия
  работают внутри каждой компоненты отдельно.

## Тесты

Локальные проверки закреплены тестами `TestShouldPruneAfterVisit_*`: нет непосещённых
(`_NoUnvisited`), одна достижимая и одна недостижимая клетка (`_SingleUnvisitedReachable`,
`_SingleUnvisitedUnreachable`), изолированная вершина в углу и в центре
(`_IsolatedVertexCorner`, `_IsolatedVertexCenter`), две изолированные клетки
(`_TwoIsolatedVertices`), валидный путь не отсекается (`_ValidPathNotPruned`).

Глобальные проверки закрывает семейство `TestAdvanced_*`: пустой остаток
(`NoUnvisited`), несвязный и связный остатки (`DisconnectedRemainder`,
`ConnectedNotPruned`), три вершины степени 1 (`ThreeDegreeOneVertices`), недоступные от
`last` принудительные концы (`ForcedEndpointsUnreachable`), отсутствие продолжения
(`NoUnvisitedNeighbor`) и пропуск глобальной проверки при одной клетке
(`SingleCellSkipsGlobalCheck`).

Эквивалентность полному скану закрепляет `TestShouldPruneAfterVisit_MatchesFullScan`,
а наивной BFS-реализации — `TestAdvanced_MatchesNaive` и `TestAdvanced_MatchesNaiveOnWalks`.
Причины отсечения сверяет табличный `TestPruneReasons`.

Фильтр записей в кэш: таблица причин `TestShouldPruneState_Reasons`;
`TestWriteGateCutsAreSound` проверяет на выборках случайных обходов досок 5×5 и 6×6, что
каждое отсечение даёт нуль у оракула полного перебора (`bruteH`) и `ForcedChain` обязана
срабатывать; `TestForcedChainCut_RequiresFixedEnd` — без зафиксированного конца отсечений
нет; `TestShouldPruneState_DegenerateRemainders` полно перебирает вырожденные остатки
|todo| ≤ 3 на доске 5×5; `TestShouldPruneState_D4Equivariant` сверяет вердикт по всем
8 симметриям `D4`. Замеры эффективности — в ADR, не здесь.
