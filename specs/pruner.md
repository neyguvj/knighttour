# pruner: отсечение тупиковых ветвей

## Ответственность

Стейт-лесс компонент необходимых условий: отсекает ветви DFS, заведомо не ведущие к полному
туру, и гейтит записи листьев генерационного спуска: ключ с нулевым числом дополнений в таблицу
не попадает.
Один тип `Pruner` (ADR-006). Не хранит статистику — возвращает причину, учёт ведёт вызывающий
через `types.Result`.

## Ярусы проверок

- **L0 — локальный dead-end**: изолированные клетки за O(deg(last)). Дешёвый первый блок.
- **L1 — глобальные** (`globalCheck`, всегда при `|unvisited| > 1`): нет продолжения у
  `last`; связность `G[unvisited]` (bitset flood-fill); эвристика концов гамильтова пути
  (degree-1 вершины обязаны стать концами).
- **L2 — гейт записи** (`ShouldPruneState`, только на листьях генерационного спуска,
  specs/searcher.md): необходимое условие существования гамильтова пути **из `cur`**,
  покрывающего `todo`, на графе `H = G[todo ∪ {cur}]`. Принятая проверка — одна:
  `ForcedChain` — union-find обязательных рёбер degree-2 вершин: корректен только при
  зафиксированном конце (ровно одна вершина `todo` со степенью 1 в `H`), иначе пропускается;
  прунит при превышении обязательной степени над путевой (>2 в todo, >1 у `cur`) и при цикле
  обязательных рёбер.

Принятый набор закрыт (ADR-030): рантайм-переключателей, масок и порогов нет (ADR-020) —
остаток на листе постоянен (`totalCells − depth`), экономить проверку на мелких остатках
не от чего.

## Публичный API

```go
type Reason uint8
const (NoReason; DeadEnd; NoContinuation; Disconnected; Endpoints; ForcedChain Reason = iota...)

func New(g *graph.Graph) *Pruner

// Горячий метод DFS: сразу после посещения last. Возвращает флаг + первую сработавшую
// причину (при false — NoReason). Инвариант: посещение last изолирует только соседей last.
func (p *Pruner) ShouldPruneAfterVisit(last int, unvisited state.State) (bool, Reason)

// Гейт записи на листе: необходимое условие «из cur существует гамильтов путь, покрывающий
// todo». Прогоняет forced-chain проверку (единственная причина — ForcedChain); L0/L1 внутри
// не повторяются — единственный вызывающий пропустил пару через ShouldPruneAfterVisit на
// спуске родителя (specs/searcher.md).
func (p *Pruner) ShouldPruneState(cur int, todo state.State) (bool, Reason)
```

## Алгоритм `ShouldPruneAfterVisit` (дешевое сначала)

1. нет непосещённых → `(false, NoReason)`;
2. одна оставшаяся клетка: отсечь (`DeadEnd`), если она не соседняя к `last`;
3. локальный dead-end соседей `last` → `DeadEnd`;
4. `globalCheck` (при `|unvisited| > 1`): `NoContinuation` / `Disconnected` / `Endpoints`.

Маски соседей не копируются — `GetNeighborMask` читает предвычисленную маску за O(1).

## Инварианты и корректность

- Ни одна проверка (L0/L1/L2) не отсекает ветвь/ключ с ненулевым числом дополнений: каждая —
  необходимое условие (связность обязательна; эвристика концов и обязательные цепочки — условия
  существования гамильтова пути с началом в `cur`). Звукосность применения L2 как гейта записи —
  лемма в specs/searcher.md.
- Эквивариантен D4 (все ярусы зависят только от структуры графа и маски) — предикат согласован
  с канонизацией ключа: «мёртвость» есть свойство орбиты.
- Стейт-лесс: безопасен для конкурентного вызова из воркеров; счётчики —
  в `types.Result.CountPrune(reason)`.
- L2 — O(V+E), V = |todo|+1 ≤ 64, без аллокаций: scratch union-find — фиксированные
  `[64]`-массивы на стеке вызова.

## Ограничения и edge cases

- При `|unvisited| ≤ 1` глобальная проверка не выполняется (одинокая соседняя клетка —
  завершающий ход, не тупик).
- Вырожденные остатки (`|todo| ≤ 3`) проверяются на общих основаниях: сработавшее отсечение
  там так же звукó (`f = 0`), а достижимые (с дополнениями) остатки остаются живы.
- `ShouldPruneState` намеренно не повторяет L0/L1: вызов идёт только на листе, чья пара уже
  прошла `ShouldPruneAfterVisit`; для проверок гейта связность `H` не требуется (условия
  компонентно-локальны).

## Тесты

`pruner/pruner_test.go`: локальные кейсы (нет unvisited / одна клетка reachable/unreachable
/ изолированные угол-центр-две / валидный путь не отсекается); вероятностная эквивалентность
полному скану (`MatchesFullScan`) и наивной BFS-реализации (`MatchesNaive`); табличные причины
(`TestPruneReasons`). Гейт записи: звукосность «отсечение ⟹ bruteH = 0» на walk-выборках
5×5/6×6 с ненулевым срабатыванием `ForcedChain`; `ForcedChain` не режет без зафиксированного
конца; достижимые вырожденные остатки `|todo| ≤ 3` живы; D4-эквивариантность предиката по всем
8 симметриям. Замеры эффективности — в ADR, не здесь.
