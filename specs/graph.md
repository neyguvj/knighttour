# graph: граф ходов коня

## Ответственность

Пакет один раз строит граф ходов коня на доске N×N и даёт к нему доступ только на чтение:
списки соседей, степени вершин и битовые маски соседей. Поиск использует эти данные для быстрой
проверки «куда можно ходить». Граф неизменяем после построения, поэтому конкурентное чтение
безопасно без блокировок.

## Публичный API

```go
func New(size int) *Graph

func (g *Graph) Size() int                // сторона доски N
func (g *Graph) GetTotalCells() int       // число клеток N²
func (g *Graph) GetNeighbors(pos int) []int        // соседи клетки pos (индексы 0..N²-1)
func (g *Graph) GetDegree(pos int) int             // степень клетки, len(GetNeighbors(pos))
func (g *Graph) GetNeighborMask(pos int) state.State // битовая маска соседей клетки pos
func (g *Graph) ShouldSkip(pos int) bool            // фильтр чётности для нечётных досок
```

`ShouldSkip(pos)` возвращает `true`, когда `size%2 != 0 && pos%2 != 0`. На нечётной доске цвета
клеток сбалансированы со сдвигом, и открытый тур обязан начинаться на клетке «большинства»;
старты другого цвета дают нулевой вклад (ADR-009).

## Инварианты

- Соседи перечислены в фиксированном порядке обхода `possibleMoves`:
  `(-2,-1),(-2,+1),(-1,-2),(-1,+2),(+1,-2),(+1,+2),(+2,-1),(+2,+1)`. Специальной сортировки нет:
  эвристика Варнсдорффа отклонена (ADR-009).
- Граф симметричен: если `b` попадает в `GetNeighbors(a)`, то и `a` попадает в `GetNeighbors(b)`.
- `GetNeighborMask` читает предвычисленную маску за O(1); вызывающий код не копирует маски.

## Ограничения и edge cases

- Поддерживаются доски до 8×8: маска соседей — это `state.State` (`uint64`).
- Преобразования «координаты ↔ индекс» нет: потребителям оно не нужно.

## Тесты

`graph/graph_test.go`: `Size`/`GetTotalCells`; соседи угла (клетка 0 на 5×5 даёт `{6, 9}`,
степень 2); центральная клетка имеет 8 соседей; индексы соседей всегда в границах доски;
симметрия рёбер; маска совпадает со списком соседей.
