# bench-table — рендер бенч-лога в markdown

**Код:** [`tools/bench_table.py`](../../tools/bench_table.py) · **Запуск:** `python3 tools/bench_table.py <log>` (обёртка `make bench-table LOG=<file>`)

## Назначение

Превращает лог `go test -bench` (`BenchmarkCountAllTours/sizeN/depthD-<procs> …`) в
markdown-таблицы — по одной на размер доски, строки — глубины по убыванию. Используется
для таблиц в README (skill `readme-writing`), ADR и отчётах бенчмаркера: таблицы в этих
местах обязаны быть сгенерированы этим тулом, а не набраны руками.

## Интерфейс

- Аргумент — ровно один путь к логу; при другом числе аргументов печатает usage и выходит с кодом 1.
- Парсятся строки вида `Benchmark\w+/size(\d+)/depth(\d+)-\d+ <iters> <value> <unit> …`;
  метрики берутся парами `значение единица` после числа итераций.
- Выход — markdown в stdout: заголовок `### N×N`, затем таблица с колонкой `depth` и
  одной колонкой на встреченную единицу (порядок — первое появление).

## Поведение и ограничения

- Единицы времени (`ns/op`) пересчитываются в `s/µs/ms`, счётчики `*/op` — в K/M/G;
  прочие единицы печатаются как есть.
- Метрики, отсутствующие в строке, — пустая ячейка.
- Пустой вход (нет ни одной бенч-строки) — сообщение об ошибке и код выхода 1.
- Только stdlib (`re`, `sys`); Python 3; переносим между darwin и linux.
