# path: ключ поиска (маска + конец)

## Ответственность

`Path` — единый компарируемый ключ всех таблиц пайплайна: пара
`(посещённая маска, текущая клетка)` (ADR-005).

## Публичный API

```go
type Path struct { ... }                 // value type: state.State + end uint8

func New(st state.State, end int) Path   // сравниваемая пара (`end` в uint8)
func (p Path) State() state.State
func (p Path) End() int
func (p Path) String() string
```

## Инварианты

- **Поля неэкспортируемы**, конструируется только через `New` — ключ неизменяем после
  создания, безопасен как map-key и для конкурентного чтения.
- `start` в ключ **не входит**: число продолжений зависит только от `(state, end)`;
  вклад орбиты переносится весом таблицы, а не полем ключа (ADR-005).
- Один и тот же тип служит ключом промежуточного аккумулятора gen A и task-cache
  (обе — D4-канон размещения); семантику задаёт конструирующий вызов, не тип.

## Ограничения и edge cases

- `end` хранится в `uint8`: валидно для досок до 8×8 (индексы < 64).

## Тесты

Покрыт косвенно (`symmetry`, `cache`): идемпотентность ключа, компарируемость как
map-key. Прямых инвариантов типа нет (структура-пара).
